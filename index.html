AI ANNOUNCER MODE

Paste your own Anthropic API key to have The System write a unique announcement for every box, live. Your key stays in this page's memory only (unless you tick “Remember keys” below) and is never sent anywhere except api.anthropic.com. Reload the page and it is forgotten.

NEURAL VOICE — FREE, IN YOUR BROWSER

A real neural voice with no key, no account, and no quota: the open-weight Kokoro model runs entirely on your machine, so nothing is sent anywhere and nothing is ever billed. First use downloads about 90 MB of model weights (once — your browser caches them); after that it is instant and works offline. Needs the hosted page, not a local file.

CLOUD VOICE (ELEVENLABS)

Optional upgrade for voice mode: paste an ElevenLabs API key and The System speaks with a genuinely acted voice instead of the browser's built-in one. Same key policy: memory only unless remembered below, and never sent anywhere except api.elevenlabs.io. If the cloud voice fails for any reason (a spent quota included), the free neural voice above takes over — or the browser voice, if that one is off too.
